# Servidor domestic amb raspberry pi per a una associacio -- PROJECTE INTERMODULAR SMX


Una associacio xicoteta necessita compartir arxius i fer copies de seguretat
amb poc presupost. Es dissenyara i implementara un servidor domestic amb una 
Raspberry Pi que cobrisca aquestes necessitats de manera segura.


## Autor
- GABRIEL(@gabserama)


## Rols simulats
- ROL A - Maquinari: muntatge i preparacio de la raspberry pi.

- ROL B - Sistema i xarxa: instalacio del sistema operatiu i configuracio de la xarxa.

- ROL C - Serveis i seguretat: arxius compartits, copies de seguretat i proteccio.


## Contingut del repositori
- `documents/` - Document de repte (Annex A)

- `documents/fitxes/` - Fitxes de activitat (Annex B)

- `configuracio/` - Configuracions tecniques (quan se execute el projecte)
